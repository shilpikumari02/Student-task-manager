Student Task Manager

A simple and user-friendly Student Task Manager web application designed to help students organize and manage their daily academic tasks.

Features

- Clean and simple user interface
- Student-focused task management layout
- Task categories for better organization
- Due-date and task-status sections
- Responsive web design

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Structure

- "index.html" – Main webpage
- "style.css" – Styling and layout

Future Improvements

- Add, edit, and delete tasks
- Mark tasks as completed
- Filter tasks by status
- Save tasks using Local Storage
